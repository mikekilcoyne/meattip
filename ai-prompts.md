# MeatTip.com — AI image prompts

These fill the bottom of the meat wall, where "the money ran out."
Save each result as `images/ai-1.jpg`, `images/ai-2.jpg`, ... (square crops work best; each file is used once).
The page tries up to `ai-80.jpg`, so more is fine.

The celebrity shots are look-alike *types*, not real people. Keep them unnamed and not quite anyone, so the site stays clear of likeness / defamation trouble.

## Paste this in front of every prompt

> Amateur mid-2000s photo, 2006 point-and-shoot digital camera, harsh on-camera flash, red-eye, slightly blurry, JPEG compression artifacts, bad white balance, orange LCD date stamp in the bottom right corner, unflattering angle, candid, not professional.

Optional, for the "crappy design" ones:

> Badly edited in early Photoshop: WordArt caption, clip-art border, lens flare, glitter text, heavy drop shadow.
